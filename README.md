# Bappebti Complaint Service Demo

Multi-portal clickable prototype for:

- Customer Site
- Bappebti Portal
- Member Portal
- Admin Console

## Local Run

```bash
npm install
npm run dev
```

## Vercel Settings

- Framework Preset: Vite
- Install Command: npm install
- Build Command: npm run build
- Output Directory: dist

This version uses plain CSS, so there is no Tailwind/PostCSS build issue.
